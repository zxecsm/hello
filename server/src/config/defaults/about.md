# Hello

> 一个集书签管理、创作笔记、任务提醒、终端管理、文件存储下载、音乐播放、图片管理、图床、在线聊天和资源分享于一体的多功能个人门户网站。

::: tip 一个私人小站
在互联网世界里，划出小小一片空间。

记录生活点滴
:::

## 关于本站

**Hello** 是一个自托管的主页应用，把日常要用的东西都收进一个页面：想记点什么、想找条链接、想听首歌，都不用再开一堆标签页。

### 功能一览

| 模块         | 说明                                                            |
| :----------- | :-------------------------------------------------------------- |
| 书签夹       | 按分组整理常用网站，支持搜索与快捷键直达                        |
| 笔记         | markdown 全语法，图片、表格、代码高亮、提示容器、锚点跳转都能用 |
| 待办与倒计时 | 记录要做的事，也记录值得期待的日子                              |
| 文件与图床   | 上传、下载、分享，图片可以走图床外链                            |
| 音乐播放器   | 本地音乐在线播放，支持切换播放模式                              |
| 终端管理     | 在浏览器里直接连服务器跑命令                                    |
| 在线聊天     | 自己人之间的聊天室                                              |
| 分享         | 把文件或笔记生成链接发给朋友                                    |
